## Suggested YouTube title and description

**Recall Check: an Alexa+ add-on that watches what you own for safety recalls**

Tell Alexa what you own. Hear about it when any of it is recalled, and what to do.

Recall Check is a self-hosted MCP server for Alexa+ that compares a household's belongings with United States recalls from the CPSC, NHTSA and FDA. Built for the Amazon Developer Hackathon, Alexa+ track.

Source (MIT): https://github.com/G-ojies/recall-check

The Alexa+ device in this video is simulated, because the Alexa+ developer tools are limited to partners. The add-on is real: every answer is a live MCP call. Narration and Alexa's voice are synthesised.
